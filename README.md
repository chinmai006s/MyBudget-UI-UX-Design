# UI-UX-Project
#MyBudget – UI/UX Design Project

#About the Project

MyBudget is a budgeting and expense management UI/UX design project created using Figma. It aims to provide a simple and user-friendly interface to help users manage their finances.

#Tools Used

- Figma
- UI/UX Design
- Wireframing
- Prototyping

#Project Features

- Budget management
- Expense tracking
- Simple and clean user interface
- User-friendly design
